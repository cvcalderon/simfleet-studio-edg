# F3.4d-2b — Activity Chain Real-CAL Runner PRE-OPEN

## Scope

This overlay implements the official controlled real-CAL runner for
`DG_ACTIVITY_CHAIN` while keeping CAL closed during PRE-OPEN validation.
It extends the frozen F3.4d-1 contract and the F3.4d-2b-R1 semantic remediation.

## Irreversible-I/O boundary

The real runner MUST validate an external authorization JSON before opening any
CAL file. The authorization is bound to the exact committed implementation HEAD,
requires a clean synchronized `main`, permits exactly three CAL files, leaves
TEST sealed, and does not authorize the next component.

The PRE-OPEN verifier and unit tests read no CAL data.

## Frozen CAL inputs

When a later authorization is issued, the only permitted CAL inputs are:

- `person_day_context.csv`: 469 rows;
- `chain_days.csv`: 319 rows;
- `chain_transitions.csv`: 1065 rows.

Physical rows opened: 1853.

The fixed propagated source cohort is exactly the 319 `context_row_id` values in
`chain_days.csv`. It is never reselected according to generated mobility state.

## Candidate universe

Exactly six frozen TRAIN artifacts:

- `DG_ACTIVITY_CHAIN::CHAIN_REF::REFERENCE`
- `DG_ACTIVITY_CHAIN::CHAIN_A::CHA1`
- `DG_ACTIVITY_CHAIN::CHAIN_A::CHA2`
- `DG_ACTIVITY_CHAIN::CHAIN_B::CHB1`
- `DG_ACTIVITY_CHAIN::CHAIN_B::CHB2`
- `DG_ACTIVITY_CHAIN::CHAIN_B::CHB3`

All enter as `FITTED_TRAIN_ONLY_NOT_SELECTED`.

## ISOLATED evaluation

The primary metric is `WEIGHTED_NEXT_ACTIVITY_LOG_LOSS` on the 1065 observed
transition rows. Observed prefix and empirical K are evaluation-only teacher
forcing; observed next activity is never supplied as a predictor.

Generated-outcome guardrails use empirical K but generate the initial activity,
subsequent activity states, and purpose attribution stochastically with 32 CRN
replicates.

`CHAIN_PURPOSE_ATTRIBUTION_V1` is the same TRAIN-only primitive for all six
candidates. Candidate identity is not included in its RNG key.

## PROPAGATED evaluation

After frozen lexicographic ISOLATED selection, PROPAGATED evaluates the reference
and provisional incumbent only. Upstream state is generated by:

- `DG_PARTICIPATION::PART_A::PA1`;
- `DG_TRIP_COUNT::COUNT_REF::REFERENCE`.

The fixed 319-day source cohort remains unchanged. A generated NoTrip contributes
zero generated transitions to M2-PURP-01 and M2-TRANS-01 and is excluded from the
M2-RET-01 generated functional-mobile-day denominator. A zero generated mobile-day
denominator is a HARD failure.

The primary log-loss is not redefined in PROPAGATED.

## Guardrails

Candidate discrepancies are averaged over 32 stochastic replicates:

- M2-PURP-01: purpose-distribution TVD;
- M2-TRANS-01: activity-transition TVD;
- M2-RET-01: absolute return-home-share error.

Pairwise worsening tolerances are respectively 0.005, 0.005, and 0.01.

## Selection

No composite score. Within each family, only HARD/guardrail-valid candidates are
eligible; the lowest primary metric is selected. Promotion requires point
improvement >= 0.01 and a paired 1000-household-bootstrap 95% CI strictly above
zero. An empty eligible family produces zero decision rows and retains the
incumbent.

## Boundaries

PRE-OPEN state:

- CAL rows read: 0;
- candidate selection: NONE;
- real CAL execution: unauthorized;
- TEST: SEALED;
- next component: unauthorized;
- G2: NOT_EVALUATED.
