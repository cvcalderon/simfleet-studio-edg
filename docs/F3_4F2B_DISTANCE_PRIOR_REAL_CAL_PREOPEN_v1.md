# F3.4f-2b — Distance Prior Real-CAL Runner PRE-OPEN

## Scope

## Irreversible-I/O boundary

## Frozen future CAL inputs
Only these files may be opened after explicit authorization: `person_day_context.csv` (469), `distance_raw.csv` (1,147), and `distance_expanded_sensitivity.csv` (1,257), total 2,873 physical rows.

## ISOLATED
All 1,147 raw-distance rows remain in scope. Upstream state is empirical CAL for component evaluation only. Five TRAIN-fitted artifacts enter unselected. Each candidate is sampled for 32 common-random-number replicates using identity `context_row_id + source_trip_id + replicate`; candidate identity is excluded from the RNG key.

Primary `M2-DIST-01` is W_GEW-weighted one-dimensional Wasserstein distance in km, computed per replicate and averaged over 32 replicates. Lower is better. The practical promotion margin is 0.25 km.

P50/P90/P95 guardrails use the mean of the 32 replicate-specific absolute weighted-quantile errors. Pairwise worsening is challenger error minus current-incumbent error and must be <= 0.50 km for every thresholded quantile. This resolves the replicate aggregation detail before the first Distance CAL row is read without changing the frozen threshold. MEAN remains mandatory report-only/unthresholded.

`M2-DIST-02` is evaluated on the expanded raw-or-source-imputed sensitivity universe and remains report-only.

## Selection
Reference -> best hard/guardrail-pass A -> best hard/guardrail-pass B. Promotion additionally requires point improvement >= 0.25 km and paired 1,000-household-bootstrap CI95 lower endpoint > 0.

## PROPAGATED
Only reference and provisional isolated incumbent are checked. The fixed cohort is the unique `context_row_id` set present in `distance_raw.csv`; it is not reselected from generated mobility. Upstream state is generated by MAIN-frozen `PA1 -> COUNT_REF -> CHA2 -> TIME_B_TB2`. Distance is generated for every generated trip.

PROPAGATED is hard-runtime-admissibility-only: generated distances must be finite and >0; forbidden route/mode/execution fields may not be consumed; no candidate/replicate-specific cohort reselection is allowed. It does not redefine the primary metric. Any propagated hard failure blocks MAIN freeze and returns to MAIN.
