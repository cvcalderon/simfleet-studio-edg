# F3.4d-1 — Activity Chain CAL Contract Freeze

## Scope

This phase freezes the controlled CAL evaluation contract for
`DG_ACTIVITY_CHAIN`. It does not read CAL and does not select a candidate.

## Frozen candidate universe

Exactly six TRAIN-fitted artifacts enter CAL:

- `DG_ACTIVITY_CHAIN::CHAIN_REF::REFERENCE`
- `DG_ACTIVITY_CHAIN::CHAIN_A::CHA1`
- `DG_ACTIVITY_CHAIN::CHAIN_A::CHA2`
- `DG_ACTIVITY_CHAIN::CHAIN_B::CHB1`
- `DG_ACTIVITY_CHAIN::CHAIN_B::CHB2`
- `DG_ACTIVITY_CHAIN::CHAIN_B::CHB3`

All remain `FITTED_TRAIN_ONLY_NOT_SELECTED` at contract entry.

The frozen TRAIN implementations are:
- CHAIN_REF: weighted first-order reference;
- CHAIN_A: terminal-aware order <= 2, `CHAIN_BACKOFF_V1`, raw source_n >= 30,
  Dirichlet alpha 0.1 / 1.0;
- CHAIN_B: regularized multinomial model, 68 features, L2 lambda 0.1 / 1 / 10.

HOME is learned and never forced. Generated chains must have exactly K transitions
and K+1 states.

## CAL evidence surfaces

The immutable F3.2a CAL materialization contains:

- `chain_days.csv`: 319 rows;
- `chain_transitions.csv`: 1065 rows.

The primary ISOLATED metric is weighted next-activity log-loss on the 1065
transition rows.

Teacher forcing of the observed prefix is an evaluation device only. The observed
next activity is never a predictor.

For generated-outcome guardrails in ISOLATED evaluation, empirical K is supplied
from the frozen chain-day target surface so Activity Chain is isolated from
upstream Trip Count.

## Primary and promotion rule

Primary:
`WEIGHTED_NEXT_ACTIVITY_LOG_LOSS`

Lower is better.

Practical promotion margin:
`0.01`.

Promotion from a simpler family to a more complex family requires all of:
1. HARD invariants PASS;
2. primary point improvement >= 0.01;
3. 95% paired household-bootstrap CI strictly above zero;
4. no frozen guardrail worsening beyond tolerance.

No composite score is permitted.

## Guardrails

- `M2-PURP-01`: purpose-distribution TVD; worsening tolerance 0.005.
- `M2-TRANS-01`: activity-transition TVD; worsening tolerance 0.005.
- `M2-RET-01`: absolute return-home-share error; worsening tolerance 0.01.

The metric implementations must reuse the already-frozen canonical F2 definitions.

## ISOLATED and PROPAGATED

ISOLATED is the candidate-selection surface.

After a provisional Activity Chain candidate is selected, PROPAGATED is mandatory
and guardrail-only. Upstream state is generated by the already MAIN_FROZEN:
- `DG_PARTICIPATION::PART_A::PA1`;
- `DG_TRIP_COUNT::COUNT_REF::REFERENCE`.

The primary log-loss is not redefined on generated upstream rows.

A propagated HARD/guardrail failure blocks MAIN freeze and returns evidence to
MAIN. There is no automatic fallback.
